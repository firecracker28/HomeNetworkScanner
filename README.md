# HomeNetworkScanner
## :military_helmet: Defend your network from unfriendly devices

## Flow
1.ARP Scan is performed on user provided network and a list of devices is found
2.Device information is determined via methods like port scanning, vendor lookups and is stored in a Object called Device
3.The information stored in Device is analyzed via a risk scoring algorithm on a scale from 1-100
4.User is given clear easy to understand insight into their score and *(planned) recommendations to improve their security.
